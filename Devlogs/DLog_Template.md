# DLog Rules

1. **Any new Day entry must be made above the previous Day DLog.**  
   The latest Day entry should always appear at the top of the DLog.

2. **All content should be mentioned point-wise.**  
   Keep development information concise and structured.

3. **The author of the DLog must mention their name without fail.**  
   The author's name should be linked to their GitHub profile.

4. **Only important entries should be made.**  
   Do not record routine, insignificant, or irrelevant activities.

5. **If another member wants to register an entry:**  
   Mention their name and GitHub profile using the `######` heading format, followed by their content.

   **Example:**

   ###### [Member Name](GITHUB PROFILE LINK)

   - Content here
   - Content here

   This is required only when the author changes. If the same author continues the DLog, simply add the new points.
